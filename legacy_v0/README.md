# Legacy V0 Archive

This directory contains the archived V0 implementation and local runtime artifacts kept for historical comparison during the Runtime V1 refactor.

Default V1 work should not read this directory. Use it only when migrating an old module, explaining V0 behavior, comparing V0/V1 design tradeoffs, or checking historical implementation evidence.

## Contents

- `app/`: archived V0 runtime package.
- `data/`: archived V0 local data fixtures and JSON stores.
- `docs/`: archived V0 project-state and learning documents.
- `entrypoints/`: archived V0 root scripts.
- `logs/`: reserved location for V0 log artifacts.
- `mcp_servers/`: archived V0 MCP demo server.
- `outputs/`: reserved location for V0 generated outputs.
- `plans/`: archived V0 implementation plans and reports.
- `tests/`: archived V0 regression tests.
