# Domain Docs

This repo uses a single-context domain-doc layout.

Before exploring domain or architecture work, engineering skills should read the root `CONTEXT.md` if it exists, then relevant ADRs under `docs/adr/` if they exist.

If these files do not exist, proceed silently. Do not create them upfront unless the current task resolves domain terms or architectural decisions that should be recorded.

Use the vocabulary from `CONTEXT.md` when it exists. If output would contradict an existing ADR, surface that conflict explicitly.
