# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues. Use the `gh` CLI for issue operations.

PRs as a request surface: yes. External PRs can run through the same triage labels and states as issues.

When a skill says "publish to the issue tracker", create a GitHub issue.
When a skill says "fetch the relevant ticket", run `gh issue view <number> --comments`.

Use `git remote -v` to infer the GitHub repo when needed.
